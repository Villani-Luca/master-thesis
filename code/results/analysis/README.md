# Analysis tables

- `finbench_table2.csv`: FinBench's published regression results (`code/finbench/results.md`, Table 2, `imgs/regression_results.png`), transcribed 2026-10-06: test MSE and MAE of the six models by universe and horizon L (lookbacks 5/20/60 for L = 1/5/20). Aggregated as in FinBench's protocol (paper §4.1: rolling test years 2020-2024, seeds 0, 5, 42; to be confirmed in the paper). FinBench's FactorVAE numbers come from its leaky test readout (issue 1 in `docs/model_notes.md`), and its MASTER, MATCC and FinFormer runs were not seeded (issue 8).
- `finbench_table7.csv`: FinBench's long-only top-5 portfolio CAGR (paper Table 7: DJI, SX5E, NASDAQ100; L = 1/5/20; benchmark rows = the index), transcribed 2026-10-17. Fractions despite the paper's "CAGR%" header (benchmarks 0.08/0.06/0.19 match the indices' annual returns).
- `finbench_comparison_regression.csv`, `finbench_comparison_portfolio.csv`: our runs next to FinBench's, by `code/scripts/compare_finbench.py` (also writes `latex-thesis/tables/finbench_{regression,portfolio}.tex`). Ours are averaged over test years, then seeds, with the standard deviation between seeds. The portfolio one needs the top-5 portfolios (`run_portfolio.py --k 5`).
